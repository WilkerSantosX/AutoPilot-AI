# Objetivo

Este documento define os artefatos oficiais produzidos durante o AutoPilot Product Development Lifecycle (APDL).

Cada artefato possui um propósito específico e representa uma etapa da evolução do conhecimento do projeto.

Os artefatos são tão importantes quanto o código-fonte, pois preservam contexto, decisões e rastreabilidade.

---

# Classificação dos Artefatos

Os artefatos do APDL são organizados em cinco categorias:

1. Estratégicos
2. Arquiteturais
3. Planejamento
4. Implementação
5. Conhecimento

# Filosofia

Todo artefato produzido durante o APDL deve contribuir para um único objetivo:

Transformar conhecimento temporário em conhecimento permanente.

Nenhum artefato deve existir apenas por burocracia.

Cada documento deve reduzir incerteza, preservar contexto ou aumentar a qualidade do produto.
